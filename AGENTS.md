This is a Python library to do comptuations of nuclei on spatial lattices,
using numpy, scipy, and jax for numerical computing, including GPU acceleration,
jax to manage distribution ("sharding") across multiple nodes,
and pytest for unit tests.

## Setup

To load the virtual environment, run the following commands
```
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt
```
