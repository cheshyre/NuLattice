When implementing new features, follow test-driven development principles.

Specifically follow the steps:
1. Implement stub functions or classes with the intended interfaces.
2. Add unit tests to test the expected behavior. In nearly all cases these unit tests should fail at this point.
3. Implement the functions or classes incrementally such that the tests pass.

Each of these steps should be at least 1 commit. The correct implementation in step 3 may be split up into multiple smaller logical commits.
